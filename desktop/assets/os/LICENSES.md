# OS asset licenses

The manifest records the intended locally bundled fonts. Font binaries are not
included in this foundation slice; package them with the corresponding license
text and upstream attribution before distributing the OS image.

## Roboto — Apache-2.0

Roboto is distributed under the Apache License, Version 2.0. Retain the font's
copyright and license notices when the font is bundled. License text:
<https://www.apache.org/licenses/LICENSE-2.0>.

## Noto Sans Devanagari — OFL-1.1

Noto Sans Devanagari is distributed under the SIL Open Font License, Version
1.1. Retain its copyright and OFL notices when the font is bundled. License
text: <https://openfontlicense.org/open-font-license-official-text/>.
